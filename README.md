Sebelumnya saya ingin memberikan pengertian singkat mengenai repository dan tujuannya. Repository adalah tempat penyimpanan kumpulan file dan kode program dalam suatu proyek. Tujuan repository yaitu untuk menyimpan dan mengelola file agar lebih teratur, memudahkan pengembangan proyek, mencatat setiap perubahan kode, serta memudahkan kerja sama antarprogrammer. Salah satu contoh platform untuk menyimpan repository secara online adalah GitHub.

Rangkuman Materi = Workshop Day 1 membahas dua hal utama, yaitu membuat aplikasi dengan bantuan AI dan mengelola perubahan serta kolaborasi dengan Git dan GitHub. Pada bagian pertama, kita mempelajari prompt engineering, yaitu cara merancang instruksi agar AI memberikan jawaban yang tepat, relevan, dan layak digunakan. Prompt yang baik memiliki struktur Role, Task, Context, dan Format, seperti pada contoh prompt Student Task Planner yang memuat tujuan, kebutuhan, batasan, dan format output. Prompt yang spesifik terbukti meningkatkan performa AI, mengurangi bias dan respons yang ofensif, serta membuat hasil lebih terkontrol dan dapat diprediksi. Kita juga mempelajari apa itu Git dan GitHub. Git adalah sistem version control terdistribusi yang melacak siapa, kapan, dan apa yang berubah pada file secara lokal, sedangkan GitHub adalah platform web untuk menyimpan repository Git secara online dan berkolaborasi. Alur kerja Git melewati tiga area, yaitu working directory, staging area, dan repository, dengan perintah dasar seperti git init, git add, git commit, git push, dan git pull

Lalu point point penting atau pengetahuan baru yang yang dipelajari saat Workshop day 1 : 
1. Prompt yang spesifik dan kaya konteks menghasilkan output AI yang lebih baik.
2. Meminta AI memverifikasi hasilnya membantu mengurangi jawaban yang terlalu percaya diri.
3. Git adalah alat pelacak versi lokal, sedangkan GitHub adalah layanan online untuk menyimpan dan berkolaborasi.
4. Staging area menampung perubahan sebelum di-commit, sehingga add selalu dilakukan sebelum commit.
5. Alur dasar version control: init → add → commit → push, dan pull untuk mengambil pembaruan.
6. SSH membuat koneksi ke GitHub lebih praktis dan aman.
